# 🤖 AI-Based ATS Resume Screener

An AI-powered ATS (Applicant Tracking System) Resume Screener developed using Python, Flask, and Natural Language Processing (NLP) techniques to help job seekers optimize their resumes for modern recruitment systems.

The application analyzes resumes against job descriptions, extracts relevant keywords, calculates an ATS compatibility score, identifies missing skills, and provides intelligent suggestions to improve resume effectiveness. The system also supports resume templates, preview functionality, and multiple file formats including TXT, DOCX, and PDF.

---

## 📌 Project Overview

Recruiters increasingly rely on Applicant Tracking Systems (ATS) to filter resumes before they reach hiring managers. Many qualified candidates are rejected because their resumes lack ATS-friendly formatting or important keywords.

This project addresses that challenge by providing an AI-assisted platform that:

- Evaluates resumes against job descriptions
- Calculates ATS compatibility scores
- Extracts and compares keywords
- Identifies missing skills and requirements
- Provides improvement suggestions
- Supports ATS-friendly resume templates

## ⚙️ Working of the System

1. User uploads a resume (TXT, DOCX, or PDF).
2. User enters a job description.
3. The system extracts text from both inputs.
4. NLP techniques are applied for keyword extraction.
5. Resume keywords are compared with job description keywords.
6. ATS compatibility score is calculated.
7. Missing keywords and recommendations are generated.
8. Results are displayed to the user.
9. User can preview and download ATS-friendly resume templates.
